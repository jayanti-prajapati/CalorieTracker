# Assets Directory

This directory contains static assets for the CalShot AI app.

## Logo
- `logo.png` - Main app logo (CalShot AI logo with green gradient and white apple icon)
  - Recommended size: 64x64px for optimal display
  - Format: PNG with transparency support

## Usage
The logo is used in:
- LandingScreen header
- DashboardScreen header
- App icon references throughout the app

## Adding the Logo
To add the logo.png file:
1. Save the CalShot AI logo image as `logo.png`
2. Place it in this `/src/assets/` directory
3. Ensure the image is optimized for mobile display (64x64px recommended)
